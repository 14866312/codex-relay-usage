# 领域文档（Domain Docs）

本仓库的领域文档布局与消费规则；后续 agent 会话在探索代码前应先读这些文档。

## 探索代码前先读

- 根目录 [CONTEXT.md](../../CONTEXT.md)（术语表）。
- [docs/adr/](../adr/) 中与当前工作区域相关的决策记录。

如果某个文件不存在，静默继续：不要提示缺失，也不要建议补建。术语与决策在真正被敲定时增量写入。

## 文件结构

单上下文仓库：

```
/
├── CONTEXT.md
├── docs/adr/0001-*.md
└── src/
```

## 使用术语表的词汇

在 issue 标题、重构提案、假设、测试名与文档里使用 CONTEXT.md 定义的说法，不要漂移到 _Avoid_ 列出的同义词。需要的概念不在表里时：要么是自造语言（重新考虑），要么是真实缺口（记下来，交给 domain-modeling 流程补充）。

## 与 ADR 冲突要显式标注

如果输出与已有 ADR 冲突，显式标注而不是静默覆盖，例如：

> 与 ADR-0002（以主文档与本地路由识别）冲突，但值得重开，因为……

## 本仓库的补充约定

- 知识库索引与更新时机见 [docs/README.md](../README.md)。
- 正文中文；代码符号、文件名与命令保留英文。
