# 费用与速度口径

本页记录金额、速度与 Token 数字的计算口径。术语见 [CONTEXT.md](../CONTEXT.md)；日志侧事实见 [codex-integration.md](codex-integration.md)。

## 费用（估算）

- 金额为美元，单价为 USD / 1M tokens；使用 decimal 计算，收起与明细的金额位数不同，小额正数不显示为零。
- 输入侧分三项：输入（含缓存读取与缓存写入）、缓存读取、缓存写入；输出单独一项。逐次按含缓存总输入选择档位。
- 两种计价模式：基础价乘倍率、直接折后价；可关闭的双档价格按阈值区分高低档；模型别名需精确完整匹配；支持分模型汇总。
- 账本按请求身份去重并与 turn_id 的模型匹配；历史缺口与异常记录会被标注。累计快照只用于 Token 展示与核对，不参与费用。
- 改价后在后台重算历史；费用发布前核对会话代次、账本身份与版本、价格版本，确保 Token 数据有效。
- 价格独立保存（`%LOCALAPPDATA%\CodexRelayUsage\prices.json`），原子保存；保存失败保留原文件并提示，界面不切换到未保存价格。
- 边界：这是按本地日志与个人配置的估算，不是中转站账单；中转站漏报／改写或 Codex 归一化零值都无法还原。

## 速度（输出速度）

- 主口径为“纯生成”：本轮累计输出 ÷ 生成类条目（Reasoning、AgentMessage）的累计时长；工具等待（命令、文件改动、MCP 调用）单列，不计入分母。
- 条目计时只在 turn_id 与 task_started 当前轮一致、时长大于 0 且不超过 1 小时时计入；新轮开始清零累计；turn_aborted 保留已累计的生成时长。
- 没有条目计时的轮次回退“本轮平均”（总耗时口径），展开行标签会标明当前口径。
- 速度按轮归属推进，在账本去重之前观测；≥100 tok/s 不丢弃小数位。
- 诊断：--speed-log-probe 按纯生成口径复算，输出生成秒数、工具秒数与生成占比，不含会话 ID、模型名与 Token 数量。

## 数字口径（Token）

- Token 用量优先使用逐次记录的 thread_token_usage 线程累计；较小快照不会降低该值；没有线程累计时使用去重调用合计；调用与累计快照绝不相加。
- 缓存读取已包含在输入中；未缓存输入 = 输入 − 缓存读取；缓存命中 = 缓存读取 ÷ 输入。
- 上下文占用 = 最近一次调用用量 ÷ 日志记录的 model_context_window（“最近调用估算”），不使用会话累计总量。
- 轮次 = 按 turn_id 去重的 task_started 数量。
- 异常值（负数、缓存大于输入、推理大于输出、总量不一致等）显示异常提示，不用输入加输出伪装为正常值。
- 展开面板不显示模型、会话 ID、更新时间和状态页脚；取数来源可通过本机诊断查看。
